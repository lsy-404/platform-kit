# Contributing

Platform Kit is developed by its maintainers only. Pull requests are restricted to repository collaborators, and outside patches are not merged.

Bug reports and suggestions are welcome.

## Report a bug

Open a [bug report](https://github.com/lsy-404/platform-kit/issues/new?template=bug_report.yml) with:

- the package and version (release tag, such as `fluent-v0.3.2`)
- steps to reproduce, ideally a minimal snippet or a link to the matching control in the [Fluent preview](https://lsy-404.github.io/platform-kit/)
- what you expected and what happened instead
- browser, OS, Node.js or Rust version where relevant

## Suggest a change

Open a [suggestion](https://github.com/lsy-404/platform-kit/issues/new?template=suggestion.yml) describing the use case and the behaviour you want. Code sketches in the issue are fine for illustration; they are read as ideas, not as patches.

## Security

Never paste access tokens, refresh tokens, cookies, private keys or production data into an issue. See [SECURITY](SECURITY.md).
