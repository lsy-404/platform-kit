# 公共用量百分比精度

## 目标

为公共 AI 用量组件增加统一的百分比格式化配置：默认 2 位小数，`0` 表示整数，`-1` 表示尽可能详细，其他非负整数表示具体小数位数。

## 边界

- IRIS 和 Toolbox 使用默认值，不在宿主中重复传入配置。
- 百分比数值本身不改写，只有展示格式统一；进度条和校验仍使用原始数值。
- 非法精度回退到默认值，不让 UI 进入异常格式状态。

## 验证

- 覆盖格式化函数的 0、默认、指定和 -1 行为。
- 覆盖 ModelAuthDialog 的默认/配置属性及窗口百分比展示。
- 构建公共 Kit 并验证 release consumer。
